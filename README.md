# QuickBite Agile Project

QuickBite is a small React application developed for COMP 354 Assignment 2.

The Sprint scope focuses on the customer ordering flow:

- PBI-01: View Restaurant Menu
- PBI-02: Select Menu Items
- PBI-03: Select Pickup Time
- PBI-04: Submit Order

## Tech Stack

- React
- Vite
- Tailwind CSS
- Vitest
- React Testing Library

## Recommended Environment

- Node.js 24 LTS
- npm 11

Clone the repository and move into the project folder:

git clone https://github.com/quickbite-agile-team/quickbite-agile-project.git
